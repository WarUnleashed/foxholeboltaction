# Foxhole Bolt Action - Colonial Legion

Unofficial New Recruit / BattleScribe data for **Armies of the Colonial Legion - Alpha 0.1**.

## New Recruit repository URL

Use this repository URL in New Recruit:

`https://github.com/WarUnleashed/foxholeboltaction`

The BattleScribe-style repository index is at the repository root as `index.xml`, with the game system and catalogue files alongside it.

## Files

- `index.xml` - BattleScribe repository index
- `Bolt Action - Foxhole.gst` - game system
- `Colonial Legion.cat` - Colonial Legion catalogue
- `Bolt Action - Foxhole.gstz` - compressed game system
- `Colonial Legion.catz` - compressed catalogue
- `Colonial_Legion_Alpha_0_1.bsr` - bundled data package

Source: *Armies of the Colonial Legion*, unofficial supplement for Bolt Action, Alpha 0.1.

This is an unofficial fan-made data conversion and may need further compatibility fixes for New Recruit's current editor/importer.
